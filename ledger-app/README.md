# 记账本 · 个人支出管家

一个面向 **iPhone** 的本地记账 PWA（渐进式网页应用）。手动记账，支持四种支付方式、自动去重、月度分类分布统计与限额预警。**所有数据只保存在你的手机本地，不上传任何服务器。**

---

## 功能一览

| 功能 | 说明 |
|---|---|
| 手动记账 | 输入金额、内容、分类、日期、备注；支持支出/收入 |
| 四种支付方式 | 微信、支付宝、中国银行、建设银行 |
| 去重（重点） | 用微信/支付宝付了银行卡的钱时，只记一笔；若误记两笔，自动识别并一键合并 |
| 月度统计 | 本月支出/收入/笔数/日均 |
| 支出分布 | 按分类的环形饼图 + 按支付方式的柱状图 + 近 6 个月趋势 |
| 限额预警 | 设置每月总限额与各支付方式单独限额，接近/超过时红色提醒 + 系统通知 |
| 数据备份 | 导出 JSON / CSV，导入 JSON / CSV |
| 离线可用 | 装到主屏后断网也能用（Service Worker 缓存） |

## 关于「去重」怎么用（重要）

你的场景：**用微信付的钱，其实是从建行卡扣的。** 这种情况如果记两笔（一笔「微信」、一笔「建设银行」），就会重复计算。

本应用的处理方式：

1. **记账时**：「资金来源」选**实际扣款的那张卡**（建行/中行），「支付渠道」可选填「微信」。这样只记一笔，统计时只算一次。
2. **如果已经记了两笔**：进入「我的 → 疑似重复（去重）」，系统会自动找出「同一天、同金额、一笔钱包 + 一笔银行卡」的记录，点「合并为一笔（保留银行卡）」即可，金额只算一次。

## 更自动的记账方式（三种，从省事到全自动）

### 1. 智能识别（最推荐、最稳定）
记账页顶部「📋 智能识别」→ 把银行短信 / 微信支付宝的支付通知粘贴进来（支持多行多笔）→「识别」→ 核对 →「确认记入」。
- 自动识别：**金额、商户、支出/收入、资金来源（微信/支付宝/中行/建行）、分类、日期**。
- 点「读取剪贴板」可一键取用刚复制的短信。
- **自动去重**：同一笔若被「钱包 + 银行卡」重复捕获，只记一笔。

### 2. URL 快捷协议（配合快捷指令/其他工具）
用网址直接写入一笔：
- 解析原文：`?text=短信原文`（可多行，自动解析）
- 直接指定：`?quick=1&amount=45&content=午饭&source=建设银行&date=2026-10-31`
「我的 → 自动化」里有可复制的模板。

### 3. 快捷指令短信自动触发（高级）
iPhone「快捷指令」→ 自动化 → 新建 → 触发条件选「信息」并指定银行号码 → 动作「打开 URL」，URL = 应用地址 + `?text=` + 短信内容 → 关闭「运行前询问」。
> 注意：部分 iOS 版本下，主屏 PWA 与 Safari 的本地存储可能不互通。若发现自动记录没同步到主屏 App，请以「智能识别」为主，或直接在 Safari 中使用本应用。

## 在 iPhone 上安装（两种方式）

### 方式 A：发布到线上（推荐，能离线 + 通知）
1. 把整个 `ledger-app` 文件夹部署到任意静态托管（或让 WorkBuddy 帮你发布，生成一个 HTTPS 链接）。
2. 用 **Safari** 打开该链接。
3. 点底部「分享」按钮 → **添加到主屏幕**。
4. 从主屏幕图标打开，即可以全屏 App 形式运行。

> 系统通知要求：iOS 16.4+，且必须是「已添加到主屏幕」后从图标打开，才会弹出授权。

### 方式 B：电脑本地起服务，手机同 Wi-Fi 访问
在电脑上执行（需已安装 Python）：

```bash
cd ledger-app
python -m http.server 8777 --bind 0.0.0.0
```

查看电脑局域网 IP（如 `192.168.1.20`），手机 Safari 打开 `http://192.168.1.20:8777`。
同样可「添加到主屏幕」。注意：此方式下离线缓存可能不可用（非 HTTPS），且电脑需保持开机。

## 数据与隐私

- 数据存储在浏览器 `localStorage`（仅本机）。
- 清理 Safari 网站数据 / 换手机前，请先在「我的 → 导出 JSON」备份。
- 导入时选择导出的 JSON 或 CSV 文件即可恢复。

## 已知限制

- 个人无法调用微信/支付宝/银行的消费记录 API，因此采用**手动录入**（你已确认）。
- iOS 纯前端 PWA 无法在后台定时推送（无服务器）；超限额时会在**打开应用时**立即提醒并尽量发系统通知。
- 原生 `.ipa` 需 macOS + Xcode 编译，本方案用 PWA 达到「装到主屏、全屏运行」的效果。
